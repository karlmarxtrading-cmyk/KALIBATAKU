MEMBUKA WEBSITE DI KOMPUTER SENDIRI

Ekstrak ZIP ke folder baru. Buka terminal di folder yang memuat package.json.
Gunakan Node 24, Python 3.12 dan jsonschema. Pada Windows Git Bash, perintah
Python dapat dijalankan dengan py -3.12. Contoh berikut untuk Git Bash.

    export PYTHONDONTWRITEBYTECODE=1 PYTHONUTF8=1
    py -3.12 -m pip install jsonschema
    py -3.12 tools/project.py verify
    py -3.12 tools/preview.py

Di Linux gunakan python3 sebagai pengganti py -3.12. Buka http://127.0.0.1:4173/
dan pilih Mulai dari dasar. Ketik jawaban, tekan Enter lalu lepaskan. Baca
Jawabanmu, kunci dan pembahasan. Enter baru atau Soal berikutnya menampilkan
ekspresi berikut dan menyiapkan input. Pada soal terakhir, lanjut membuka
hasil tersimpan. Tindakan baru dari hasil membuka misi berikut. Peta dan
katalog dapat dipakai kapan diperlukan. PRATINJAU.html memuat tangkapan UI.

GIT BASH WINDOWS, GITHUB DAN CLOUDFLARE PAGES

Untuk bukti Windows asli, ekstrak ke path berspasi lalu jalankan pada Git Bash

    bash VALIDASI_EKSTERNAL/verifikasi-windows.sh

Simpan folder hasil di samping proyek. Instruksi dan pemeriksaan asal hasil
tersedia di VALIDASI_EKSTERNAL/07_WINDOWS_NATIVE.md. Untuk penerbitan oleh
operator berwenang, ikuti docs/DEPLOY.md. Dari GitHub, hubungkan cabang
validasi ke proyek preview terkontrol. Gunakan direktori output dist dengan
isi persis build yang diuji. Simpan bukti, kit dan cadangan di luar dist.
Syarat promosi serta hasil sesungguhnya tercantum di STATUS_RILIS.md.

MENJAGA PEKERJAAN SISWA

Pilih Profil aktif → Unduh cadangan profil. Simpan di luar folder situs.
Saat restore, buka pratinjau cadangan dan periksa alias, duplikat, konflik,
sesi, draf serta riwayat sebelum menyetujui. Untuk update, simpan ZIP lama
dan ID deployment. Coba update di origin serta subpath yang sama dengan
profil sintetis, termasuk dua tab dan misi offline. Untuk rollback, aktifkan
deployment utuh terdahulu pada target yang berizin, tutup seluruh tab lalu
buka kembali dan bandingkan riwayat serta draf. Pertahankan data situs.
