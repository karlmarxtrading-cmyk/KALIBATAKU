# Temuan selama perbaikan

Saat matriks pengujian diperluas, ketukan Lanjut yang sah dapat diabaikan di Chromium. Browser mengirim nomor klik berurutan walaupun siswa sudah beralih ke soal lain dan memeriksa jawaban baru dengan keyboard. Pemeriksaan tombol kemudian dibatasi pada perintah penunjuk yang bersangkutan. Di layar lanskap 844 × 390, bagian bawah tombol Mulai juga terpotong. Pengaturan jarak vertikal di beranda pendek diperbaiki. Hasil pemeriksaan antara tersimpan sebagai pra-final; bukti resmi kandidat ada di folder qa.

Saat menyusun uji keterlambatan font dan renderer, Playwright sempat mencoba melanjutkan request yang telah dilepas. Harness akhir menahan dan melepas byte aset asli di server HTTP lokal. Di Firefox, uji pembahasan sempat merekam perubahan posisi sesudah fokus native pada summary. Kontrol HTML tanpa JavaScript aplikasi dapat menghasilkan pergeseran yang sama. Regresi akhir memeriksa posisi langkah pembahasan yang sedang dibaca sesudah fokus native stabil. Hasil observasi antara dapat dibaca dalam native-focus.log. Pengukuran akhir serta bukti geometri berbeda per mesin tersedia di viewport-comparison.

Pengujian cache lama dan putaran historis gagal dicatat terpisah dalam observasi-offline. Ringkasan kesiapan mengambil hasil build final dari binding QA.
