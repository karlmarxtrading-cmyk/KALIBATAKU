# Lingkup dukungan KALIBATAKU 1.6.2

| Konteks | Bukti dan batas penggunaan |
| --- | --- |
| Ponsel dan keyboard | Matriks Chromium, Firefox dan WebKit mencakup ukuran viewport, sentuhan, orientasi, peristiwa komposisi/IME dan tombol layar yang ditentukan tiap suite. Perilaku keyboard perangkat Android/iOS asli dapat berbeda. Tombol **Periksa** dan **Soal berikutnya** tersedia. Saat layar sangat pendek atau diperbesar, rumus panjang dan kontrol dapat dijangkau melalui gulir. |
| Aksesibilitas | Bukti otomatis mencakup struktur semantik, nama/role, fokus, navigasi keyboard, teks matematika ID/EN dan tampilan pada kondisi uji. Ujaran NVDA, VoiceOver, TalkBack dan konformitas aksesibilitas menyeluruh belum divalidasi. |
| Laporan | DOCX memuat persamaan OMML. Pemeriksaan menggunakan pembacaan struktur dan render LibreOffice. Gunakan PDF bila tata letak tetap dibutuhkan. Tampilan pada Microsoft Word belum divalidasi. |
| Windows | Windows dapat menggunakan distribusi prabuild dari folder dist. Hash, newline dan path berspasi memiliki pemeriksaan tersendiri. Klaim CI Windows native membutuhkan receipt pelaksanaan di Windows pada identitas build yang sama. |
| Progres | Penyimpanan lokal terikat profil browser dan origin. Pada perangkat bersama, pilih alias yang tepat. Gunakan cadangan untuk berpindah perangkat/domain. Misi baru di luar jaringan membutuhkan aset yang sesuai telah tersimpan. |
| Hasil belajar | Skenario siswa/guru memakai data sintetis. Kesiapan pos merupakan aturan permainan. Latihan, evaluasi formal A/B, dan bukti efektivitas pembelajaran memiliki makna berbeda. Efektivitas dan kepuasan belajar belum diukur pada peserta. |
| Operasi | Pengujian laboratorium mencatat anggaran performa pada mesin uji. p75 lapangan memerlukan pengamatan pascapenggunaan. Status `local_hosting`, preview penyedia dan domain produksi dapat dibaca di register serta keputusan aktif. |

Riwayat bukti 1.6.1 dan peta pengganti gerbang tercantum di `REGISTER_PEMETAAN_HISTORIS.csv`. Paket berisi materi lokal/sintetis dan ruang guru simulasi. Mengirim laporan atau menyimpan cadangan berisi profil nyata merupakan keputusan operator atau keluarga.
