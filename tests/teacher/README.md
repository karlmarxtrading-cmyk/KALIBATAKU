# Teacher workspace and report verification

Run these commands from the release root. The synthetic fixtures, stress reports, renderings, and results are written under `evidence/teacher/`.

```sh
node tests/teacher/exports.mjs
python3 tests/teacher/inspect_exports.py
```

The rendering check uses LibreOffice (`soffice` on PATH), PyMuPDF, Pillow, python-docx, openpyxl and jsonschema. The strict handoff ReportSnapshot is nested under the `core` key of `parents-report-1.0`. The surrounding object carries scope, subjects, timestamps, class and operation breakdowns, policy evidence, notes, sessions and filter semantics. CSV text fields are escaped for common spreadsheet formula prefixes. Workbook strings use explicit inline strings and numbers use numeric cells.

To run the top-level browser test with normal browser downloads, use `python3 tests/teacher/browser.py` after installing the Playwright Python package and its Chromium browser. Set `CHROMIUM_PATH` for a compatible alternative executable. Only synthetic data is used in an isolated browser context. Optionally start `python3 tests/teacher/serve.py` then open the locally printed test console URL and click **Run end-to-end checks**. This console validates the actual bytes generated by the browser export worker before operating-system save-dialog handling. It accepts QA results at loopback and is outside the deployed site.

Within the teaching workspace, two administrative classes and six synthetic aliases are stored separately from private practice. Historic example sessions are marked as synthetic. New submissions flow through the same player, namespace, event ledger and mock transport used by exercise mode. The staff transaction log retains original and revised notes. An override is a separate reasoned teaching decision. Only a configured institution can verify academic grades in the future.

PDF uses the bundled DejaVu Sans font and checks character coverage during export. A character unsupported by the bundled font yields an explicit font coverage error. DOCX preserves Unicode text and uses the viewer's available font fallback. Browser JSON reports are for integration and review. Restore from the separately versioned backup format in device settings.
